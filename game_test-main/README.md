# 랜덤 캐릭터 디펜스 (Random Character Defense)

HTML5 Canvas 기반의 싱글 파일 랜덤 캐릭터 디펜스 웹 게임입니다.

## 바로 플레이하기
👉 **[게임 바로가기 (GitHub Pages)](https://wjsrlfdnd-gif.github.io/game_test/)**

## 주요 기능
- **로비 시스템**: 월드 & 스테이지(`n-1 ~ n-10`, 무한 모드), 아이템 상점(65종 장비·소모품), 장비 강화·분해, 일일 퀘스트·업적, 특성 연구소
- **전투 시스템**: 유닛 소환 및 일괄 합성(신화·초월 조합 재료 자동 보호), 7단계 등급 및 시너지, 현상금 보스·전체 궁극기·배속 전환
- **모바일 & PWA 지원**: 가로/세로 화면 대응, `localStorage` 자동 저장, 오프라인 캐싱(`sw.js`)

## 주요 단축키
- `Space`: 유닛 소환
- `M`: 일괄 합성
- `1` / `2` / `3`: 전투 중 등급별 강화 (일반~레어 / 영웅~전설 / 신화~초월)
- `B`: 현상금 보스 소환
- `S`: 전체 궁극기 발동
